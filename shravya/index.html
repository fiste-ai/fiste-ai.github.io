Use it

Request access on the model page, then:

Terminal
pip install onnxruntime numpy soundfile soxr huggingface_hub
hf auth login
hf download fiste-ai/shravya --local-dir shravya-model
python shravya-model/shravya.py clip.wav

One Python file, no graphics card. No punctuation yet, and phone calls are still hard. Weights CC BY-NC 4.0, code MIT. Using it at work? Ask for a demo or a commercial licence.

Shravya Live (preview)

Shravya Live writes the text while someone is still speaking, every 640 or 320 ms. When the speaker pauses it reads the phrase once more as a whole, and that is the text to keep. Word error rate in percent on the same five test sets.

Terminal
python shravya-model/shravya.py --model shravya-model/live --stream clip.wav

It comes with the same download, in the folder live, and runs 8 times faster than real time on one thread of a desktop processor. It is a preview: measured on recordings, not yet on live calls.
